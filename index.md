# Chrome Windows Switcher Support

Chrome Windows Switcher is a macOS utility for quickly finding and activating open Google Chrome windows.

## Get help

Before opening a support request, please check that:

1. You are using macOS 14 or later on a Mac with Apple silicon.
2. Google Chrome is installed and running with at least one normal browser window open.
3. Chrome Windows Switcher is allowed to control Google Chrome under **System Settings → Privacy & Security → Automation**.

If the issue continues, [open a support request on GitHub](https://github.com/viktorkelemen/chrome-windows-switcher-support/issues/new). Describe what happened and the steps needed to reproduce it. Please remove private window titles, screenshots, credentials, and other personal information before posting.
